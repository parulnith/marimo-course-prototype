# AI Coding Agents in marimo

AI coding agents work best when they are part of your working environment from the start. marimo's built-in assistant does exactly that as it can generate or edit a single cell, while [`marimo pair`](https://docs.marimo.io/guides/generate_with_ai/marimo_pair/) connects a coding agent to a running notebook so it can inspect and change several cells. In this module you'll look at multiple ways to use AI coding agents in marimo, and how to give them the context they need to work effectively.

## 1. Generate and edit with the AI assistant

The quickest way to use AI in marimo is to generate a new cell or modify an existing one. We will use these features to build a small sales analysis dataset.

### Enable AI features

If you are running marimo locally, first connect an AI provider:

1. Open the notebook settings. You can also click **Generate with AI** in the notebook to open the AI settings.
2. Select **Optional Dependencies** and check that the AI features are installed.
3. Next, open the **AI** tab. Choose a model provider and model. For a hosted provider, add its API key. You can also use an open model through Ollama. Follow the [provider setup instructions](https://docs.marimo.io/guides/configuration/llm_providers/) for your choice.

### Extend the analysis

Now ask AI to turn the dataframe into a chart. In an AI prompt, `@df` gives the assistant the current dataframe, including its columns and values. Generate another cell with this prompt:

```text
Using @df, add a bar chart showing total profit by channel. Sort the bars from highest to lowest profit and name the chart channel_profit_chart.
```

Run the cell and inspect `channel_profit_chart`. Confirm that each bar shows the total profit for one channel, rather than an average. Check the bar values against the interactive dataframe. Treat this as a short exercise.

### Edit the generated cell

You can also use AI to edit a cell it has already generated. Select the chart cell and press `Ctrl/Cmd-Shift-E` to open the edit prompt. Enter:

```text
Add a horizontal line showing average channel profit. Keep the output named channel_profit_chart.
```

Run the edited cell. The line should show the average of the channel-profit totals.


## 2. Using the Chat panel

Use marimo's Chat panel to ask questions about your notebook or ask the assistant to make changes. In this section, you will extend the sales analysis and see how each mode changes what the assistant can inspect, run, or change.

Let’s now extend the analysis and analyse sales performance. Open the Chat panel from the left sidebar, then choose a Chat mode. Each mode gives the assistant a different level of access.

### Choose a Chat mode

#### Manual

In **Manual** mode, the assistant is pure chat with no tool access. It uses only the context you add. Review its answer in Chat, then choose whether to copy its code or add it to the notebook. Use this prompt in **Manual** mode:

```text
Using @df, analyze sales performance by region and segment. For each region and segment combination, calculate total revenue, total profit, conversion rate, and average satisfaction. Identify the combination with the highest profit, the one with the lowest satisfaction, and one combination to prioritize. Explain your recommendation. Do not change the notebook.
```

<img
  src={manualModeScreenshot}
  alt="A response in marimo Manual mode with Copy and Add to Notebook buttons."
/>

#### Ask

In **Ask** mode, the assistant can use read-only tools to gather context. For example, it can inspect the notebook or search documentation, but it cannot change the notebook. Use it when you want the assistant to analyse the work you have already done and explain its findings.

Use this prompt in **Ask** mode:

```text
Inspect the notebook and analyze channel_profit_chart. Explain which channel is most profitable, how the chart supports that conclusion, and what additional analysis would help you decide where to focus next. Do not change the notebook.
```

<img
  src={askModeScreenshot}
  alt="A detailed read-only analysis of a chart in marimo Ask mode."
/>

#### Agent

In **Agent** mode, the assistant can use the same read-only tools as Ask mode. In addition, it can also add, update, or remove notebook cells and run stale cells. Use it when you want the assistant to make a focused change to the notebook.

Use this prompt in **Agent** mode:

```text
Add a Markdown cell below channel_profit_chart that explains what the chart shows. Keep the explanation to two sentences. Do not change any existing cells.
```

#### Code mode

In **Code mode**, the assistant works directly with the live [notebook kernel](https://docs.marimo.io/guides/editor_features/tools/#code-mode). It can use the notebook's current runtime state and carry out more involved notebook tasks.

Use this prompt in **Code mode**:

```text
What happens if revenue increases by 10% for every sale while costs stay the same? Without creating or editing any notebook cells, use the live notebook kernel to calculate projected revenue and profit by channel. Identify the channel with the largest profit gain, explain the result, then discard the temporary calculation.
```

## 3. Work with a coding agent using marimo pair

The Chat panel is great for focused tasks. For deeper computational or data work, you can pair-program with an AI coding agent through [`marimo pair`](https://marimo.io/pair). The live notebook becomes a shared workspace where you can ask questions in plain language, ground the answer in code, and keep work that you can rerun and build on.

`marimo pair` is a skill that connects an agent directly to an active marimo notebook session. You can use it with Claude Code, Codex CLI, Cursor and other compatible agents. The agent can inspect live variables and outputs, run cells, update the notebook, and work with its controls.


### Start pairing

To start pairing, first choose an AI coding agent. This example uses Codex, although marimo pair supports other agents.

```bash
# Install the Codex plugin:
codex plugin marketplace add marimo-team/marimo-pair
codex plugin add marimo-pair@marimo-pair
```

Next, either connect Codex to a notebook that is already open or let it start the notebook for you.

#### Connect to an open notebook

Start the notebook:

```bash
uvx marimo@latest edit notebook.py --sandbox --no-token
```

In the marimo editor, open **Settings → Pair with an agent → Codex** and follow the instructions. Omit `--no-token` if other people can access the server.



#### Let the agent start the notebook

You can also ask Codex to start a fresh notebook and begin the pairing session. 

```text
/marimo-pair with me on notebook.py
```

## 4. Review AI-generated work

AI-generated code still needs review. Check that it answers the request, that its output agrees with the data, and that it follows marimo's notebook rules.

[`marimo check`](https://marimo.io/blog/marimo-check) is a notebook linter for humans and coding agents. It finds marimo-specific problems that can prevent a notebook from running cleanly, such as variables defined in multiple cells or circular dependencies.

After an assistant or agent changes a notebook, run it from the repository root:

```bash
uvx marimo check marimo_notebook.py
```

Read any reported issues and fix them before keeping the changes. A clean check does not confirm that the analysis is correct, so also inspect the output and compare it with the data.

An interactive notebook is a great place to begin an AI or ML project because it lets you experiment and test ideas quickly. However, your requirements may change when you need to share your work or integrate it into a larger production system.

marimo lets you move from a notebook to a script, web app, shareable artifact, or reusable Python module without rewriting your code and in this module, you will see exactly how to do this.

## 1. Start with a notebook

Imagine you work for a company that wants to understand sentiment in customer feedback. In this exercise, you will use two open-weight LLMs to classify twelve product reviews as positive, negative, or neutral using zero-shot classification. You will then compare how the models label the same reviews.

<img src={sentimentClassifierFlow} alt="Twelve product reviews go through a zero-shot prompt to two Ollama models. Each model returns sentiment labels, and the results are compared." />

### Set up Ollama

This time you'll be working with local, open-weight models through Ollama namely `gemma3:1b` and `qwen3:1.7b`. These small models download quickly and can run on most local machines. In **Module 4**, you saw how to configure AI providers in marimo. For this notebook, enable AI features and select Ollama as the provider. 

<details className="setup-details">
  <summary>Set up Ollama and download the models</summary>

  1. Download and install [Ollama](https://ollama.com/download).
  2. In a terminal, start the local server:

  ```bash
  ollama serve
  ```

  3. In a second terminal, download the two models for this module:

  ```bash
  ollama pull gemma3:1b
  ollama pull qwen3:1.7b
  ```


</details>

### Run the starter notebook

The notebook below is the starting point for this module. It contains twelve product reviews, two controls for choosing models, and a button to run the comparison. These controls are widgets, like the ones you used in [Module 3](/?module=3). When you select **Classify with both models**, marimo sends every review to each model. Each model returns a sentiment label, confidence score, and short reason. The results appear in a dataframe, with one row for every review and model pair.

## 2. Run a marimo notebook as a script

You have used the classifier interactively. Now run the same comparison from a terminal when you need a repeatable result that can be saved to a file.

<MarimoEmbed notebook="/notebooks/1_sentiment_classifier_script.html" title="Sentiment classifier script" />

The script accepts two model names and an output path. `run_headless()` reads the arguments after `--`, runs the comparison, and writes the dataframe to CSV.

```bash
cd course/notebooks/module-5
uv run python 1_sentiment_classifier_script.py -- \
  --model-a gemma3:1b \
  --model-b qwen3:1.7b \
  --output results.csv
```

Open `results.csv`. It should contain 24 rows with the review text, model name, label, confidence score, and explanation.

## 4. Export and share a report

The script creates a CSV file. This report notebook reads that file and gives you a simple view that you can export or share.

<MarimoEmbed notebook="/notebooks/3_sentiment_classifier_report.html" title="Sentiment classifier report" />

Export the report when you need a file that someone else can open:

```bash
marimo export html 3_sentiment_classifier_report.py -o report.html
marimo export pdf 3_sentiment_classifier_report.py -o report.pdf
marimo export html-wasm 3_sentiment_classifier_report.py -o wasm_output --mode run
```

Use HTML for a report that someone can open in a browser, PDF for a fixed document, and WASM when you want a browser-based interactive version.

## 5. Reuse the classifier in another notebook

The comparison logic can also become a Python module. `classifier_module.py` exposes `get_client()` and `compare_two_models()` with `@app.function`, so another notebook can import them.

<MarimoEmbed notebook="/notebooks/eval_pipeline.html" title="Evaluation pipeline" />

The evaluation pipeline uses the same functions with a new set of reviews. It does not copy the Ollama connection or comparison code.

```python
from classifier_module import compare_two_models, get_client

client = get_client()
results = compare_two_models(client, texts, model_a="gemma3:1b", model_b="qwen3:1.7b")
```

</TryIt>

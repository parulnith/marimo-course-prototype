The task

Meeting rooms report light and CO₂ readings. A scoring rule combines them into a score between 0 and 1, and a reading counts as occupied when its score is at or above a decision threshold. This report compares those predictions with the recorded occupancy for the same readings.

Results at the selected threshold

The trade-off

A false positive treats an empty room as occupied, so lights and air conditioning may stay on. A false negative treats an occupied room as empty, so lights could switch off on people. Raising the threshold can only reduce false positives and can only add false negatives; lowering it does the opposite. The right choice depends on which mistake costs more.
